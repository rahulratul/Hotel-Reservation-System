# Hotel Reservation System

A browser-based Hotel Reservation System that runs entirely in the browser using local storage for data persistence.

## Team Members & Roles
- **Leader / Member A**: Room Catalog (`feature/room-catalog`)
- **Member B**: Reservation System (`feature/reservation-system`)
- **Member C**: Guest and Dashboard (`feature/guest-dashboard`)

## Technology Stack
- **Structure**: HTML5
- **Styling**: CSS3 (vanilla)
- **Logic**: Vanilla JavaScript (ES6+)
- **Data Storage**: Browser localStorage

## How to Run
To run the application, clone this repository and open `index.html` in a web browser using a local development server (such as VS Code's Live Server or `python3 -m http.server 8000`).
